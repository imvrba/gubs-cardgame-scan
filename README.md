# README.md
- Upload of Gubs card deck png files that contain all game cards.
# imvrba - 06/10/2026

/images
- Contains every png file for replicating deck.
- File names contains the card name and after the underscore the quantity of that card in a standard 70 card deck.
- Back.png is the standard background for all cards.
- FrontManual.png contains the rules of Gubs.
- BackManual.png contains the rules of each card.

Warning:
Gubs cards have been photographed with an iPhone 13 Pro and digitally altered and upscaled with ChatGPT Pro (06/10/2026). At some point I may revisit this and upload honest to god raw scanned in images of the deck. I was personally satisfied with the results.
